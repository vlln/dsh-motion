# 卡：一个风格的全部知识

一张卡就是一个风格。**卡是可增长的资产，引擎不变。**

风格不是引擎里的一个选项——所以它在这儿，是一份 markdown，加一个场景文件，加一次并排图和一次打分。

## 卡长什么样

```md
# <名字> · <年代/来源>

**对照物：<我对着哪一张判>**（一张，不是一批；盲评按这一张判）

状态：研究配方 | 单场景实做 | 跨场景验证
适用：一句话说清它管什么（题材、尺度、画幅）

## 管线
1. 静态层怎么画（缓存一次）
2. 每帧画什么（便宜）
3. 角色/主体怎么处理
4. 表面/媒介怎么过一遍

## 色板
墙 #eadcb8 → 暗部 #d8c597；四色边框 红 #b8322a 蓝 #2a58a8 黄 #e2b13a 绿 #2e8a55
（写关系，不要声称这是标准色）

## 签名特征
- 必须有：……
- 加分：……
- 禁忌：……

## 坑
- 具体到能复现：参数、数值、写错了会怎样

## 短板
- 现在哪里最差，下次做它先超越这一条
```

## 状态三档（凭证据）

| 状态 | 什么时候可以写 | 不许说 |
|---|---|---|
| **研究配方** | 有来源和视觉假设，没实现或没并排 | 「会做这个风格」 |
| **单场景实做** | 走完六步：有实现、有并排图、有打分记录（≥80） | 「跨题材可用」 |
| **跨场景验证** | 不同新场景各自过一遍，写清覆盖范围 | 「所有题材都行」 |

**没走过 [`protocol/新风格.md`](../protocol/新风格.md) 的六步，不许登记为实做。**

## 怎么加一张

1. 照六步做，别跳步。
2. 把做法写进卡（管线、色板、签名、坑）。
3. 在 [`INDEX.md`](INDEX.md) 加一行，状态写实情，**短板不许留空**。
4. 做对了的事写进卡的管线；被推翻的结论**改掉原句**，不要在新段落里解释。

卡不是教程，是**下一次做它时要读的那一页**。
