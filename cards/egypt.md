# 埃及墓室壁画 · 新王国 / 阿马尔纳，约 1350 BC

**状态：研究配方**（走完六步，打分 **74**，未到 80）

适用：横向栏带、平涂、无透视的叙事画面；适合「一个人走过一幅壁画」这类镜头。

样例：`examples/egypt/`（8 秒，1920×1080，30fps）。并排图：`examples/egypt/out/look/vs-ref.jpg`。

## 管线

1. **静态层**（`ctx.still`）：墙、上下彩块边框、齿带、象形字栏（位置在 `mount` 里算好一次）、
   池塘深色框、陶罐、供桌。
2. **每帧**：池塘水面（齿纹 12fps 步进）+ 鱼（各自速度连续游）+ 水鸟浮动 + 莲花开合 +
   圣甲虫推日球 + 走路的少女。
3. **角色**：不走通用骨架，按埃及程式现画——侧脸 + 正面眼 + 正面肩 + 平涂 + 等宽线，
   白帽子是「穿越」的标记。
4. **表面**：最后过一遍 `flatten(g, W, H, PALETTE)` —— 压到 15 色闭合色板。
   这是这套风格最要紧的一步（见「坑」）。

## 色板

墙 `#e9dcbe`，暗部 `#d8c69c`；线 `#24180f`（暖深棕，不是纯黑）；
红 `#b03a2e` / `#c8372b`，蓝 `#2b57a8` / `#1d3a7a`，绿松 `#3f9a94`，绿 `#35794a`，
金 `#d9a63a` / `#efce7a`，米白 `#f4ecd8`，肤色 `#d99a63` / `#b5763f`。

压色板之后整幅落在 **15 个颜色**里（对照参考帧 127 色——那是 GIF 的调色板上限，不是画的上限）。

## 签名特征

- **必须有**：无透视平涂；等宽深棕轮廓线（1080 高度下约 3px）；栏带构图（横条 + 彩块边框）；
  象形字成栏；侧脸正面眼、正面双肩。
- **加分**：彩块边框在红蓝黄绿之间交替；水面用交错齿纹而不是波纹线；水鸟、鱼、莲花做密度；
  圣甲虫推日轮。
- **禁忌**：任何笔触噪点；渐变；透视缩短；投影/高光；把象形字画成装饰涂鸦。

## 坑

- **不要先想「叠一层颗粒」**。埃及壁画的质感来自颜料吃进灰泥，不是来自噪点。
  我试过整幅 `multiply` 一层斑驳（α 0.9），结果水纹被吃掉、轮廓断裂、墙变成橙斑——比不做更糟。
  正确幅度在 4% 以内，而且只作用于墙面，不作用于图形。
- **压色板要分深色和浅色两组找最近色**。不分的话，3px 描边有一半像素被判成墙色，线会断。
- **象形字的缩放按高度算，不按栏宽**。按栏宽算会得到 4 个字一栏的巨大字形。
- **人的比例**：这一版仍然是木偶（细胳膊、方块躯干），是最大的短板。
- 静态层一定要 `ctx.still`，否则每帧重画整幅墙会把 16ms 吃光。

## 短板

1. **造型**（9/15）：人物是木偶，没有重量；圣甲虫读成了小虫。下一次先把人重画：
   加宽躯干、画出肩三角、手臂用锥形笔画、脚要有脚背。
2. **密度**（签名 28/35）：参考里几乎没有整块空白墙，我的下栏有大片空。下一次按参考数
   每 100px² 的母题数，把陶罐、莲花苞、供品、小鸟铺满下栏。
3. **表面**：现在是绝对平涂，读起来像矢量图。需要一层**很轻**的灰泥斑驳（≤4%），
   只压墙面。
