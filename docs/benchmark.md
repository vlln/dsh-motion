# 基准：这个系统的分数

## 为什么有这一页

埃及那张卡跑了九轮盲评，分数 47 → 65 → 52 → 62 → 52 → 61 → 60 → 61 → 64。
**这是那张卡的分数，不是系统的分数。**

系统的分数是另一件事：**一个没参与过这个仓库的 agent，拿到一句话题目和说明书，
从 `init` 开始，能做出什么。** 换了引擎、换了 `kit/`、换了 `howto/`、换了 SKILL，
该变的是这个数。

上一轮我把这两件事混了：六轮重画同一张画，净变化为零；而系统的改动
（色板工具、生图通道、表面移植、howto 重写）一次都没有用"新 agent 的产出"验证过。

## 怎么跑

固定三个 brief，**一个字都不要改**——改了就没法比。

| # | 题目 | 首次成绩 |
|---|---|---|
| 1 | 一杯茶凉掉的过程 | 51 |
| 2 | 地铁进站时的一阵风 | 55 |
| 3 | 一枚硬币在桌上转到停下 | 37 |

每次跑：

1. 一个**新 agent**，只给：工作区路径、账号、题目、一句「照 `skills/dsh-motion/SKILL.md` 做」。
   **不给任何提示**——不提色板、不提生图、不提参考。
2. 它必须交：带音轨的 MP4，`check --deliver` 全绿。
3. 交付后派**另一个**没参与制作的 agent 盲评，用它自己判断的对照物，同一套审片问句。
4. 记进下表：交付了没有、多少分、它自己报"猜"了几处。

### 第 4 行说明什么

同一句 brief，分数 55 → 50，**在噪声内，等于没动**。而且重复缺陷**三条全在**：

1. 媒介是「矢量图 + 网点叠加」，不是丝网印：网点等径、零套位、纸边是色框。
2. 主体图标化：人无臂无脸无影；车头长成一张脸。
3. 风只作用在道具上，人没有反应。

**结论：这九轮系统改动，没有作用在「agent 画不出来」这件事上。** 色板工具、文档结构、
命名、门禁都对，但它们不是瓶颈。两个真缺口被这次基准照出来：

- **生图工具在 agent 手里不可用**（provider 配错，调用直接报缺 key）。
  这是唯一被证明能解决造型的杠杆，实际没接上。
- **只有判据，没有造法**：`审片.md` 教了怎么判媒介，没教怎么造媒介；
  `从参考里取.md` 说「抄源码」，但这个 agent 没有源码可抄，于是自己发明了一套贴图。


三次的共同结论（当时）：

- 三次都交付、都没有向引擎要画法 → **"风格不能预置"这条成立**；
- 自评比盲评高 20–35 分 → **判据必须盲评**；
- 三次的媒介都被判"矢量图加纹理" → **媒介是系统的短板**。

## 判据

**系统改动的价值 = 重复缺陷的减少，不是某张卡看起来好了。**

- 改完之后重跑同一批 brief，分数不动 → 那个改动对系统没价值，哪怕它让某张卡涨了 3 分。
- 分数涨了 → 记下来是哪一条改动导致的，写进 [`howto/从参考里取.md`](../howto/从参考里取.md)。
- 只有一条 brief 涨、另两条跌 → 说明改动绑定了那个题材，不是系统能力。

## 已知的偏差

- 盲评的**人**每次不同，分数有 ±5 的噪声。三次同题、同一张表，只能看趋势。
- agent 的自评分系统性虚高，不进表也可以，但留着能看出"它知不知道自己做得差"。
- 题目本身有难易差：硬币（37）明显比茶（51）难，别横向比，只纵向比同一题。
