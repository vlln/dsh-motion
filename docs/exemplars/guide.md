# 样板 · guide（纸上印刷）

`dsh-motion init --template guide` · 6 秒 · 1440×1080 · 源码 `src/starters.mjs` 的 `id: 'guide'`

**一句话**：一本手绘动物图鉴的对页，一台青色扫描器扫过，读出编号。

## 靠什么成立

1. **纸先于画。** `paper()` 铺底色、纤维、斑驳，然后才是内容。没有纸，任何线条都像屏幕上的图形。
2. **两种笔。** 标题条和色块是"印刷"（硬边、网点），引线和猫是"手绘"（抖边、错位、粗细不匀）。
   一整页都是同一种笔，就成了矢量插画。
3. **轻微套印错位。** 色块比线偏 1–2px。这点误差是"印出来"和"画出来"的分界。
4. **一个事件。** 扫描器扫过 → 编号读出。整页只有这一件事在发生；其余是排版，不是动效。
5. **只有两种主色**（青绿 + 蓝灰），加纸本身。颜色一多，图鉴就变成海报。

## 抄什么

- `paper()` 打底 → 网点/纤维 → 内容 → 最后统一一次暗边；
- 线用 `inkStroke`（手绘）与 `roundRect` 填充（印刷）分开；
- 让"事件"藏在一个小装置里（扫描线、指针、翻页），而不是让整页动。

## 换什么

换题材（图鉴 → 说明书、菜单、地图）、换两种主色、换那个小装置。

## 常见抄错

- 用同一支笔写所有东西（没有印刷/手绘之分）；
- 整页都在动（没有事件）；
- 颜色超过三种（纸的味道被冲掉）。
