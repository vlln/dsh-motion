# 样板 · plate（拿一张画当世界）

`dsh-motion init --template plate` · 8 秒 · 1920×1080 · 源码 `templates/plate/scenes/plate.mjs`（约 150 行）

**一句话**：一张公版油画是整个世界，里面只有一个 10fps 的小像素人在走。

## 靠什么成立

1. **密度是借来的。** 整幅画的笔触（十万笔量级）没有一行代码画它。代码只负责：窗口在哪、谁在走、
   什么挡在前面。这是全片"贵"的唯一来源。
2. **演员是另一种材质。** 15 色的像素人 + 一格黑描边，和油画完全不匹配。观众认出"这是两个东西"，
   靠的正是这个不匹配；给它加笔触去"融入"画面，两边就糊成一张图。
3. **两种节奏。** 世界只有机位在动（推 10%、漂 16%），演员 10fps 换帧、不补间、每 8 步跳一格。
   世界的 24fps 和演员的 10fps 是这镜头"活"的来源，不是转场。
4. **前景一挡。** 九根草从画面下缘长上去，压过演员的腿——它才在画里，而不是贴在画上。
5. **一次 grade。** 颗粒（pattern 平铺，每步错位）+ 暗角，全片统一。没有这两样，画会"浮"在屏幕上。

## 抄什么

- 起手顺序：`ctx.image('plate', { fit:'cover', focus, w, h, x, y })` 决定窗口；
- 演员：`ctx.paint.sprite(g, rows, palette, { scale, outline })` + `Math.floor(t*10) % frames`；
- 前景：几根代码画的草/栏杆/雨丝，画在演员之后；
- 收尾：颗粒 + 暗角。

## 换什么

换 `assets/plates/night.jpg`（公版图，见 `CREDITS.md`）、换演员的 10×13 字符网格、换草的疏密。
**不要换**的是五条结构——换了就不成立。

## 常见抄错

- 把演员画得和画一样厚（材质对撞消失）；
- 让画本身动起来（那就成了"代码画的动画"，密度反而更低）；
- 忘了前景遮挡（演员浮在画上）；
- 演员太小（低于画面高度的 15%，观众读不出它在做什么）。
