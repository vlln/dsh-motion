# 样板 · pond（底图 + 笔触层）

`dsh-motion init --template pond` · 12 秒 · 1920×1080 · `templates/pond/scenes/pond.mjs`

**一句话**：黄昏的池塘，睡莲在漂，水光在闪。**整幅没有一条直线，也没有一个矩形。**

## 三层

| 层 | 做什么 | 什么时候算 |
|---|---|---|
| ① 底图 | 只铺颜色分布：天空渐变、树线（椭圆堆的）、水面、右岸 | `mount()` 里画**一次**，缓存 |
| ② 笔触层 | 网格从底图取色，按区域定方向、按区域换色板，画短笔 | **画一次**（`boil: 0`），缓存 |
| ③ 活的东西 | 睡莲漂、水光闪（10fps 换位）、涟漪外扩 | 每帧，画在笔触层之上 |

## 关键手法

1. **区域由颜色判断，不按坐标切。** 按 `y > 地平线` 切会切出一条笔直的边——正好是要避免的东西。
   `zoneOf(r,g,b,x,y)` 从底图那一点的颜色判出"天 / 水 / 芦苇 / 岸"，再用低分辨率区域图给
   `mask` 和 `palette` 共用。交界处自然化在笔触里。
2. **两种笔触分两遍。** 第一遍整幅、方向按区域；第二遍只给芦苇和石岸，竖笔更密——
   不然那些区域会被横笔抹平。
3. **整幅不沸腾。** `boil: 0`，笔触层画一次就冻住。
   第一版按参考实现的 `boil: 6` 全屏重抖，结果**每一帧都在跳**，看几秒就头晕——
   参考实现只让母题区域沸腾，静止区是 0，我把这条用错了。
4. **睡莲也是笔触。** 不是 `ellipse().fill()`，是沿叶缘和叶面画的一圈圈短笔——否则它就是一张
   贴在油画上的贴纸。

## 抄什么

- `ctx.still(draw)` 画底图 → `ctx.paint.strokes(base, {angle, palette, mask, boil})` 盖笔触层 →
  元素画在层上；`zoneOf` + 低分辨率区域图这套分工；
- `ctx.paint.swatch([...], 0.4)` 给每个区域一套色板，混底稿色保明暗。

## 换什么

换题材（麦田、菜市场、雨后街道），换区域划分，换漂的东西。

## 常见抄错

- **整幅开 boil**（逐帧跳变，头晕）——笔触层是画，不是频闪；
- **用匀速平移当"运动"**——那是幻灯片推拉；要么缓入缓出地推，要么让元素自己走；
- 按 y 或 x 切区域（切出直线边界）；
- 每个区域一遍笔触、且每遍都用 `cell` 相同（该密的密不起来）；
- boil 开到 24（读成闪烁），或者不开（画面死了）；
- 把会动的东西画成纯矢量（一眼贴纸）。
