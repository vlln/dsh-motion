# 样板 · street（代码画，但有材料）

`dsh-motion init --template street` · 8 秒 · 1920×1080 · `templates/street/scenes/street.mjs`（约 230 行）

**一句话**：雨后的夜街，路灯下有一洼水；一张纸杯被风吹过，灯在 5.2 秒闪了一下。

## 它解决的是那个真实失败

一个冷启动 agent 做过同题材：能跑、能看，但 `texture 2.7`——因为它**每帧重绘几何**，
于是永远不敢过材料（过一遍太慢）。这个模板就是那条断掉的桥。

## 靠什么成立

1. **画一次。** `ctx.still(drawMass)` 把世界画进一张和渲染同尺寸、同坐标系的画布。只在 `mount()` 里执行一次。
2. **上材料一次。** `ctx.medium.broken(base, { density: 0.7, size: 0.5 })` 再 `film()` 过一遍镜头。
   笔触大小按画幅算（`size`），夜里的暗处不描厚涂边（暗笔画的黑边会把画面变成一团毛）。
3. **只画**大块**。** 天空、楼影、路面、光锥、水洼的"形体"交给材料；**细到笔触会吃掉的东西**
   （车道虚线、灯杆灯头、水面反光、涟漪）每帧画在最上面，和底板一起缩放，保持对位。
4. **雾是带状的，不是滤镜。** `mist` 出来的一层用渐变蒙版裁成地平线一带，再叠回画上——
   整幅糊一遍会把笔触全糊掉；把它当成"远处的空气"，不是"给画面加个雾的效果"。
5. **动的东西少。** 机位缓推 + 雨丝 + 三个涟漪 + 一次灯闪 + 一个 8fps 步进的纸杯。
   全部都是"画在底板之上"的，底板本身不动。
6. **值结构先于材料。** 天空在地平线那里有一道城市辉光，楼影才立得住；路面比天空亮一档。
   没有这层明度结构，材料通道只会把一片黑糊成一片黑。

## 抄什么

- `ctx.still(draw) → medium.broken(…) → medium.film(…)` 这三步；
- "大块交给材料、细线画在上面"的分工；
- 笔触尺寸跟着画幅走（`size`），暗处不描边。

## 换什么

换题材（后巷、站台、地下车库），换光源，换那个被风吹过的东西。

## 常见抄错

- 每帧重绘几何（材料就永远上不去）；
- 把车道线、灯泡也交给材料（细东西会被笔触吃掉）；
- 笔触开到很大（一片"面条"）；
- 暗部也描厚涂边（夜戏变毛皮）。
