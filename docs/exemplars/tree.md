# 样板 · tree（绢本水墨）

`dsh-motion init --template tree` · 6 秒 · 1080×1440 · 源码 `src/starters.mjs` 的 `id: 'tree'`

**一句话**：一棵树立在绢上，湿笔从下往上长出来，末梢墨点随后一个个落上去。

## 靠什么成立

1. **绢是底，不是滤镜。** `paper({ base:[239,231,212] })` 给的是绢的米色和纤维；墨是画在上面的。
2. **墨有浓淡和飞白。** 一笔里有干湿变化（`inkStroke` 的 `dry`），不是等粗的线。
3. **生长有先后。** 主干先长、枝再分、点上最后落——一帧全干就没有"长"这回事。
4. **月是淡墨，不是发光盘。** 一个低透明度的径向渐变，边缘化开；画成亮圆就是插画。
5. **一点朱红。** 全画只有印章是饱和色，其余全是墨与纸。那一点红把整幅画钉住。

## 抄什么

- 底（绢/纸）→ 湿笔（浓淡）→ 干笔（飞白）→ 墨点 → 印；
- 用时间轴控制"先后"（`span(t, a, b)`），不要用整体透明度。

## 换什么

换主体（竹、山、鸟）、换印文、换纸色。

## 常见抄错

- 墨线等粗等黑（变成线稿）；
- 月/日画成亮的圆（发光感）；
- 全画只有一个时间进度（所有东西一起出现）。
