# examples · 四部完整示例

这四部片子**不是**模板，也不是「照这个做」。它们是证据：某条路线跑通过，代价和结果都记在下面。

| | 题目 | 结论 |
|---|---|---|
| [`egypt/`](egypt/) | 埃及墓室壁画（8s，带音轨） | **研究配方**，九轮盲评最高 65。它证明了生图给人物、照参考量色板、照源码抄表面这三条路线；也证明了卡在媒介和密度上。 |
| [`cold-start-1/`](cold-start-1/) | 一杯茶凉掉的过程（11.4s） | 独立 agent 自己发明了双版木口木刻；盲评 51。 |
| [`cold-start-2/`](cold-start-2/) | 地铁进站的一阵风（11.0s） | 麻胶版三色套印；盲评 55。 |
| [`cold-start-3/`](cold-start-3/) | 一枚硬币转到停下（10.8s） | 铜版画排线；盲评 37。 |

三次冷启动全部交出带音轨的 MP4、`check --deliver` 全绿、**没有一次向引擎要过画法**。
三次盲评全部低于自评 20–35 分——这条记录在 [`docs/cold-start.md`](../docs/cold-start.md)。

`motion/out/` 不入库（渲染产物）；场景、时间轴、审片记录都在。
