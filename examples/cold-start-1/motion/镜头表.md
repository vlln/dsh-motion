# 镜头表 —《一杯茶凉掉的过程》

> 11.4 秒，1920×1080，30fps，四镜。全片一套画风：**奶油纸上的双版木口木刻**（墨黑主版 + 朱红副版）。
> 第 0–8 节是 SKILL.md 要求填的八项；第 9 节是我替自己做的决定和理由。

---

## 0. 一句话

一个人把茶倒进盏里就走了。观众看完记住的是：**没有人来喝，红色先走，蒸汽最后走。**

## 1. 观众

知道「茶会凉」这件事，不需要被解释原理。需要被说服的是：**凉是一个看得见的过程，不是一句字幕。**
所以不解释、不报温度、不出图表；只让蒸汽变细、红从杯沿缩回杯里、液面结出那层薄皮。

## 2. 参考（量过的，不是想象的）

取自 Wikimedia Commons / Rijksmuseum，CC0，三幅不同作品，只量、不进片：

| 图 | 是什么 | 我量到的 |
|---|---|---|
| `assets/plates/ref-stilleven-a.jpg` | 荷兰木口木刻静物（A. C. W. van Starrenburg） | 纸 `#ead6bc`；暗部不是灰，是**顺体积的平行刻线**；投影是一块**硬边实墨**；版外有版痕 + 版下一行小字 |
| `assets/plates/ref-stilleven-b.jpg` | 铜版静物（骷髅与陶罐） | 纸 `#e0c8a9`；最深处 `#564d41`；线细而活，桌面的排线带 4° 斜切；纸有纤维与黄斑 |
| `assets/plates/ref-chiaroscuro.jpg` | 明暗套色木刻（1522，Varnbüler 肖像） | **两块版**：黑主版 + 灰橄榄调子版 `#77786b`；背景是一整片同向细平行线，不是实底；高光就是没印的纸 `#dcd9be` |

**5 条签名特征**

| # | 特征 | 等级 |
|---|---|---|
| 1 | 体积由排线的**方向与密度**生成（线顺结构走），没有一处渐变或喷枪 | 必须有 |
| 2 | 亮部 = 没印的纸；最暗 = 小面积实墨 | 必须有 |
| 3 | 硬边 + 手工痕：轮廓线粗于内部排线，边缘有崩口、白点 | 必须有 |
| 4 | 版内是画、版外是纸：版痕、版下窄边、版下小字 | 必须有 |
| 5 | 背景是一整片同向细线（调子版），与主体上顺体积的线形成方向差 | 加分 |
| — | 禁忌：径向渐变 / 模糊 / 发光 / 在矢量上叠噪点 / 均匀灰填充（灰必须由线距生成）/ 蓝紫 | 禁忌 |

**这种画在物理上怎么做出来的**：梨木块上刻掉要留白的地方，滚墨，压到纸上；第二块版只刻茶水与热度，对准了再压一次。
所以本片**光是纸、暗是刻线、红是第二块版**——三条都写进了画法，不是滤镜。

**构图规则（学它组织画面的方式，不搬它的物）**：
主体偏右、占版高三分之一强；桌面是一条横线把画面压下；左上一块**窗光留白**（不刻线）；
整幅四周留一道版痕；题字压在版下的窄边里，小字、疏排。

## 3. 画风三行

- **画风**：奶油纸上的双版木口木刻（黑主版 + 朱红副版），形由刻线生成，硬边，手工崩口。
- **色板**：`#eee3cd` 纸 · `#221d17` 墨 · `#9c3a26` 朱红（茶水与热度）· `#8a7d6a` 淡墨 · `#d8c9ad` 纸灰。
- **角色**：无。人始终不出现——这是题意（「没人来喝」），也是版画的规矩：只画物。

## 4. 导演策略

- **结构**：全景（放好的一盏茶）→ 蒸汽（缓推）→ 液面（横移、微距）→ 拉出版外（收）。
  四镜的镜头动作依次是 停 / 推 / 移 / 拉，没有重复。
- **节奏**：3.2 / 3.2 / 2.4 / 2.6 秒。前两镜平，第三镜慢到底，第四镜一口气拉开——
  片子的转折是「观众忽然发现自己在看一张印出来的纸」，不是情节转折。
- **情绪线**：红退 → 蒸汽断 → 字印出来。温度只由这三件事报，不写一个数字。
- **声音**：一层室内底噪 + 一层很轻的 pad；四个事件 cue（陶器轻响、推近、液面、最后一缕蒸汽断）。
  最后 1.6 秒只剩底噪。
- **结尾落在**：蒸汽最后一缕断掉，同时版下印出「茶凉了」——动作和字同一秒发生。

## 7. 验收

1. `check --deliver` 六条全绿（有画面 / 有声音 / 长度对 / 无空画面 / 不是幻灯片 / 不是蓝紫）。
2. 抽帧排一排：能指出每帧是「哪一镜里的哪个物在做什么」。
3. 拉到最后 1 秒时，画面上的纸边、版痕、版下小字都看得见——即「这是印出来的」这件事成立。

## 9. 我自己定的事（说明书没给，或没写清）

- **题材给了，画风没给。** 按 `protocol/新风格.md` 第 1 步量了三幅参考（上面第 2 节），
  选「双版木口木刻」而不是水墨／像素／埃及，理由：茶的凉是**减法**（蒸汽走、红走），
  而木刻正好是减法媒介——刻掉的地方才亮。红当第二块版，正好装「热度」这一件看不着的东西。
- **没有人。** 角色克制到零：一只手会抢戏，而且手是木刻里最容易画成橡皮手套的东西。
  人只以「倒好了就走了」这个既成事实上场（第一镜的涟漪就是证据）。
- **不写字幕、不报温度。** 全片只有片尾三个字。
- **时长 11.4 秒**，不是 10：第四镜的拉需要一个不赶的速度（2.6 秒），压到 2 秒就像抽走。
- **帧率 30**：本片没有快速横摇，30 够；导出快一半。
- **调色板名 `main`**，六个必需 token 都给了值（`bg` 纸 / `fg` 墨 / `accent` 朱红 / `muted` 淡墨 / `grid` 纸灰 / `panel` 浅纸）。
- **参考图留在 `motion/assets/plates/`**（CREDITS.md 有出处），但**不进片**——片子是完全代码画的。
- **`audio.json` 不写 `length`**：SKILL.md 明说不要写（`examples/egypt/motion/audio.json` 写了，两处矛盾，见报告）。

## 10. 做完之后改掉的三件事（记录在案，不是事后合理化）

1. **墙从"一整片刻线"改成"第二块版的平色 + 主版细线"。**
   一开始按参考里的"同向细平行线"整片刻，出来是条形码（2px 线 + 4px 缝，1920 宽下读成电子屏）。
   改成明暗套色那块**平色**打底（量自参考 `#77786b`，压到 `#7d7864`），黑主版在上面走细线，
   才是参考里"调子版 + 主版"的关系。**这一条推翻了镜头表第 2 节的第 5 条签名（背景同向细线）**：
   留着，但降级为"加分"，因为真正让人读出"这是版画"的是两块版的关系，不是线的方向。
2. **盏身的暗面从"竖排线"改成"斜排线 + 起刀不齐"。**
   垂直满高的排线在盏身上读成"百叶窗"或"贴上去的一块"，界线是一条刀切似的竖缝。
   现在是斜 8°、靠界线起刀晚、颜色淡，暗部看起来是"长出来的"。
3. **加了版底色（`#e5d7ba`）和版痕。**
   没有它，最后一镜拉回全张时"纸边"和"画面"是同一个色，观众看不出这是一张纸。
   版痕 + 版底色是这张片子唯一一处"纯装饰"，但它承担的是第四镜的全部意义。
