# 镜头表 · 地铁进站时的一阵风

> 8–12 秒，1920×1080，30fps，11.0s。三镜。
> 本表按 protocol/镜头表.md 八节写满；空缺处都是我自己定的，理由写在括号里。

## 一、一句话

下班的人站在站台上等车，先等到的不是车，是车推过来的那阵风；风把围巾吹横，车停稳、门缝一亮，风就走了，围巾落回肩上。
（观众看完记住的：**风比车先到**。这是真的——列车像活塞，把空气顶在车头前面。）

## 二、观众

- 已知：地铁是什么样、进站是什么感觉。
- 需要被说服的：不是"地铁很快"，而是**那股风有方向、有先后**。所以三镜的事件顺序必须是
  「空气先动 → 光源先来 → 车体才到 → 风停」，不能反过来。
- 不需要解释：怎么买票、去哪一站。全片不做交代性镜头。

## 三、参考

**没有现成参考。** 手边没有可量的风格图或成片，按 protocol 的降级条款：自己定三个方向，选一个，
并写清为什么选它。（如实登记：本片**没有**走「量三幅原作」那一步，所以它不是"新风格"的成果，
只是一次自己的画法实验。）

| 方向 | 一句话 | 为什么不选 |
|---|---|---|
| A 苏联构成主义海报 | 斜线、红黑米、粗字，速度感强 | 太容易变成"模板海报"，而且斜构图和"站台是水平的"打架；字一多就成 PPT |
| B 铅笔速写 | 软、轻、生活感 | 铅笔一软就和"风"抢：风要硬边才读得出方向；也最容易画成"AI 铅笔" |
| **C 木刻/麻胶版画三色套印（选它）** | 大面积墨黑 + 刻出来的白线 + 一点信号黄，纸是米色的 | 版画的**白线就是刀刻出来的风**——这个题材里的风本来没有形体，只有刻痕能给它形体；墨块又能承载"黑隧道/黑车体"这两个必须的黑 |

**学什么**：黑白面积比（墨占 45% 左右，留白让光成立）、刀痕的平行与断口、三色套印的错位。
**不学什么**：不搬任何具体版画作品的构图、人物、纹样。

## 四、画风（全片只用这一种）

- **画风**：木刻／麻胶版画，三色套印——米色纸、暖墨黑、信号黄，外加一点锈红做第二版。
  形靠"刻掉"（白线从墨块里露出来），不靠描边。
- **色板**：`#e8e0cb` 纸 · `#171310` 墨 · `#e9b83f` 信号黄 · `#a9422b` 锈红 · `#8d8069` 暖灰。
- **角色**：只有一个背影男人（后脑、肩、大衣、围巾、手插兜），没有脸；站着不转身。

**签名特征（逐条打钩用）**

1. **必须有**：大面积实心墨块，形由纸色的**刻线**分出来（刻线宽度 3–7px，不是描边）。
2. **必须有**：三色以内套印（纸／墨／黄，锈红只做第二版小面积），**平涂，无渐变、无发光**。
3. **必须有**：平行排线（刀痕）表示暗部、速度和距离；线的角度跨镜头不变（约 42°）。
4. **必须有**：边缘有刀的抖动和缺口（不是平滑贝塞尔），尤其墨块的轮廓。
5. **加分**：套色错位——黄版整体偏移 (+3,−2)px。
6. **禁忌**：渐变、辉光、蓝紫、噪点滤镜、彩色写实、平滑矢量描边。

**这种画在物理上怎么做的**：麻胶版上刻掉要"白"的地方，滚墨，压到纸上；第二块版上黄，
对不准就错开两三像素；纸上留下纤维和刀口的毛边。所以本片的"媒介通道"是：
**形先画成块 → 再让块过一遍刻痕（缺口/白线）→ 纸纤维垫在底下**，而不是"平涂上撒噪点"。

## 五、导演策略

- **结构**：三镜，一个因果链——等（静）→ 风先到（推）→ 车到、风走（快→停）。
- **节奏**：0–3.4s 慢（只有纸杯滚、围巾动）；3.4–7.2s 中（灯涨、风涨）；7.2–11s 快→停（车体横扫、减速、门缝亮）。
  全片只有一次"快"，就是车体扫过，其余都是等——**不平均用力**。
- **情绪线**：无聊 → 察觉 → 被推了一把 → 一切归位。
- **声音**：站台底噪 + 风（两层铺底）；三镜各一个重音：纸（1.5s）、车轮闷响（6.7s）、到站提示音（8.8s）。
  最后一秒只留底噪与风尾。
- **结尾落在哪**：落在**围巾落回肩上**这一个动作上，不是金句卡，不是片名。

|---|---|---|---|---|---|

- 相邻两镜换构图：透视全景 → 低机位近景 → 平视横移。✅ 画风不换。✅
- 文字主导：只有吊牌一个数字，占比≈0。✅

## 七、素材

| 素材 | 怎么得到 | 得不到怎么降级 |
|---|---|---|
| 全部画面 | **代码画**（scenes/_print.mjs + 三个场景） | —— |
| 纸的纤维 | `mount()` 里画进离屏底图（4000 根短线） | 没有就少一层，形还在 |
| 光斑边缘的点阵 | `mount()` 里预生成一张点阵图，`render` 里裁切成光斑形状 | 没有就用硬边黄块（会硬一点，仍成立） |
| 字体 | 只用系统字体角色 `mono`（一个数字 `3`） | 数字刻成图形 → 不做，风险大于收益 |
| 音乐/音效 | `motion/audio.json` 用 make-audio 合成（无采样、无版权） | 已合成，无需降级 |

**自己定的、说明书没规定的决定（都记在这里）**：

1. **一个字都不写**，只留吊牌上的站台编号 `3`。理由：站台本来就没有台词；任何一句"风来了"都会
   把片子降成说明文。CJK 字体不在四种系统角色里，硬写有 tofu 风险，所以正文放弃。
2. **30fps**（不是 init 默认的 60）。理由：版画是"硬切"的媒介，30fps 已经够；60fps 只会让渲染慢一倍。
   代价：车体横扫的拖影要靠 3–4 帧一条的刻痕来做，不能靠高帧率。
3. **风的方向全片一致（画面左→右）**：列车从左边隧道来，空气被顶在车头前面同向走。
   所以纸杯向右滚、围巾尾向右横、风线全部向右倒。
4. **不做台词、不做片名卡、不做片尾字**：结尾是一个动作（围巾落下），不是一句字。
5. **人物不给脸**：只用背影和插兜的手。这是画风三行里写的，也是避免幼稚感的唯一办法。
6. **第二镜里没有人物**（改过主意）。原表写的是"隧道口 + 飞舞的围巾"，画的时候发现：低机位近景里
   人只能切在画框边上，而围巾是向右飞的——从右边的画框飞出去的围巾看起来像在往画面外跑，和
   风的方向打架。所以第二镜只拍洞和灯，人留到第三镜收尾。**牺牲**：三镜里只有两镜有人。
7. **门缝开在 9.7s**（第三镜第 2.5 秒）。让"风走"和"门开"是同一下，最后 1.3 秒留给围巾落下来。
8. **音轨的 cue 与画面对位**：page 1.5s（报纸/纸杯被吹起）、wheel 6.5s（车体扫过）、
   bell 9.8s（门缝亮开）。铺底只有两层（roomtone + wind），按说明书上限来。

## 八、验收（三条，可判定）

3. 每镜至少一帧里，墨色实块之外的**刀痕**看得见（放大 1:1 检查，不是平涂+噪点）。
