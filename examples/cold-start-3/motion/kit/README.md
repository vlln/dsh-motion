# kit/ — 样例，不是 API

这里放的是**某个年代的一种实现**，不是引擎的一部分。

- 引擎（`src/`）**从不 import `kit/`**；删掉整个 `kit/` 目录，`dsh-motion` 照样启动、照样出片，只是画不出东西。
- `init` 把它复制进项目。你可以改、可以扔、可以只留一个文件。
- 需要这里没有的画法时，**写在你自己的场景里**（或者项目的 `scenes/_*.mjs`），不要往 `kit/` 里加，更不要往引擎里加。

| 文件 | 是什么 | 什么时候看它 |
|---|---|---|
| `brush.mjs` | 笔触、平滑路径、锥形笔画、水墨叠色 | 笔触画法 |
| `medium.mjs` | 两个媒介通道：`broken`（重绘成笔）、`fresco`（颜料吃进墙） | 形层画完要过一遍画材 |
| `pixel.mjs` | 低分辨率栅格、调色板量化、1px 描边、抖动 | 像素／闭色板画法 |
| `perspective.mjs` | 一点透视摄像机 | 画面需要纵深时 |
| `figure.mjs` | 骨架、两节 IK、四肢、步态 | 画面里有人且要动 |
| `grade.mjs` | 可选后期：泛光、暗角、颗粒、冷暖分离 | **只在需要时才调**——平涂和像素画调了会毁掉色板 |

原书里的那句提醒值得抄在这里：**风格成立靠的是程式、色板、纹样密度，不是最后叠一层噪点。**
