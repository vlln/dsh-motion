# 自我复核（不是独立审片）

**先说清楚：这份不算 `howto/交付.md` 的第三道。**
本次会话被限制「不能再派子 agent」，我没法找一个没参与制作的 agent 只看成片。
下面是制作人自己隔一天回看的口径，**只能当自评**，不能当盲评；按打分表的规定，自评会虚高。

复核对象：`motion/out/video.mp4`（10.80s / 1920×1080 / 60fps / 含 aac 音轨）。
复核日期：2026-10-25。

## 一、看到了什么

一枚浅色硬币立在深色桌面上自转，桌子是密排线的铜版画质地；硬币越转越斜，
边缘接地点绕着桌面画圈，影子跟着扫；最后它倒下、弹一下、停住，镜头从低处抬到币面，
一道高光从币面走开。声音是低频房间底噪 + 一层很轻的和声垫，起转有一声木轮似的低鸣，
两个切点各一下轻响，倒下时一高一低两声铃，之后安静。三镜的构图分别是低机位、俯拍拉远、
近景俯拍推进，切得很硬，没有淡入淡出。

## 二、哪里看不懂

1. **墙上的亮块**：左边一块亮的竖条是窗光，但边界是直的，远看像一盏打歪的聚光灯，
   不像窗。第一镜里它占了近一半画面，会让人先看它而不是币。
2. **左边那半枚币**：第二镜左边缘露出的平放硬币被切掉一半，第一次看会以为是画面脏了，
   或者以为主角分裂了。它是尺度参照，但露得太少。
3. **币面上的几道弧线**：那是自转的多重轮廓，不是划痕。定格看很像刻坏的线；
   连续看能读成转，但第一眼不友好。
4. **币值「1」**：一眼是「1」，但桂冠 + 1 的组合太像通用图标，读不出这是哪一枚币、为什么转。
   题目只要求「一枚硬币」，这不算错，但少了点具体的物性。

## 三、哪里像模板

- 中心构图 + 推拉 + 结尾停在主体上，是安全牌；三镜之间没有真正的「事件转折」，
  只有同一个动作的三个阶段。结构对，但没有惊喜。
- 铜版画这套语言里，真正的签名是「手刻的毛边」；现在线太干净，远看像矢量图叠了排线纹理，
  这是最像模板的地方。
- 音色是引擎自带的 pad + bell，安全、不抢戏，但也没有为这一枚币专门设计一个动机。

## 四、哪里不该动（下一版保留）

- **硬切**：三镜直接切，不要加淡入淡出。切点落在 70BPM 的第 4、8 拍上，和 `click` 对得上。
- **币的边缘**：齿边的暗带 + 受光侧的纸白刻线，是这个片子唯一像金属的地方，保留。
- **8.57s 的撞击与镜头抬起**：先跟着币沉下去、再抬起来看币面，这个运动比一路推进好，保留。
- **最后的静止**：停住之后只留尘粒、光和铃的余响，不要加字幕或金句。

## 五、打分（自评，只用来排序）

| 项 | 分 | 依据 |
|---|---|---|
| 签名命中 | 30/35 | 五条里四条成立：排线承担明暗（弱）、暖纸深赭无纯黑纯白、硬边+纸白高光、无蓝紫/霓虹/滤镜/有脸币；「手工上色只上两种」只做到赭石一种，冷青灰几乎没出现，扣 5 |
| 媒介可信 | 10/20 | 1:1 看：排线密度够，纸边和版痕可信；但轮廓是抗锯齿矢量边，浮雕是纸白填充+墨线，缺凹版的压痕和吃墨，判「数码线稿」而非真铜版 |
| 构图与叙事 | 12/15 | 三镜构图不同、事件一眼可读（立转→摇→倒→停）；墙光块抢戏、副币露得太少，扣 3 |
| 造型 | 10/15 | 币有厚度、齿边、浮雕，影子有重量；但桂冠和 1 仍偏图标，读不出具体币种，扣 5 |
| 动态 | 8/10 | 多重轮廓 + 影子扫 + 镜头先降后升，活而不闪；高速段的轮廓扇有频闪风险，扣 2 |
| 技术 | 5/5 | 确定性通过；每幕 16.7ms（测量下限）；`check --deliver` 六条全绿 |
| **合计** | **75** | 无否决项（签名 30≥25，造型 10≥8） |

**75 < 80。** 按 `howto/打分表.md`，这条只能记「研究配方」，不能写「实做」。
要过 80，最该先改的是「媒介可信」：把币面浮雕从填色改成排线塑形，把轮廓做毛，
让纸纹吃进线里；其次是换掉通用桂冠币，给这枚币一个具体的身份。

## 六、三条最该先改

1. **浮雕换成线**：数字 1 和桂冠不要纸白填充，改成「留白 + 一侧密排线」，
   让凸起由线的疏密读出来；现在的白块是图标感的主要来源。
2. **线做毛**：给每条排线加 0.5–1px 的抖动和断口，尤其是币缘和墙根；
   矢量边是「一眼数码」的根源。
3. **墙光改成窗**：把左上的亮块改成有窗棂投影的斜四边形，或者干脆去掉，
   让币自己撑住画面；现在那块光比币抢眼。
