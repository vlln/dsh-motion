# 审片：固定的问句，不是分数

## 为什么没有分数

有过一张 0–100 的打分表，门檻 80。它借自参考仓库的 95 分协议，用了九轮，最后证明它做不成事：

- **它分辨不出差异。** 同一个 brief 跑了两次，一次 55、一次 50——差 5 分，在盲评噪声里。
  系统改了九轮，这个数字没动，但也没告诉我为什么没动。
- **它邀请调参。** 评审说「线宽应该 6–7px」，我就把默认值改成 5.6。那是照着数字调参。
  还有一次「加接触影让画面落地」，数字掉了一分——它连方向都指不准。
- **它压缩掉了唯一有用的部分。** 两次盲评里真正起作用的是同一句话重复出现：
  「网点是等径的」「矢量图加纹理」「人无臂无脸无影」。那些是**缺陷**，不是分数。

所以改成**固定问句 → 缺陷清单**。可比性来自问句相同，不来自数字。

## 审片人怎么答

盲评委托里必须写清**对照的是哪一张**。然后照这四问答，每条都要指到画面上的具体位置：

### 1. 它自称什么媒介？这个媒介的硬指标成立吗？

先让它说清是哪种画材（丝网印、木刻、壁画、水彩……），再逐条查那个媒介的物理特征。常见四条：

| | 成立要看到 | 不成立的样子 |
|---|---|---|
| 墨/料的厚薄 | 同一块色里明度不匀、边缘积墨 | 纯色填充，RGB 恒定 |
| 版的错位 | 套色交界露纸白或叠出第三色 | 零错位、直切 |
| 亮部是底材 | 纸/墙本色透出来 | 另一种白颜料 |
| 标记是做的，不是画的 | 线宽随形体变、有起收 | 等宽描边、端点圆齐 |

**缺两条以上 → 媒介不成立。** 这一条是硬闸门。

### 2. 有没有「一眼是图标」的主体？

是／否。是的话指出**是哪一处**（人没有手臂？车头长成一张脸？手是几何形）。

**是 → 这一版不许登记为「实做」。** 不是扣分，是没做完。

### 3. 事件能读出来吗？

观众不看字、不看你的说明，能不能说出**这一镜在干什么**。
不能的话，缺的是哪一步（缺方向？缺对象？缺反应？）。

### 4. 三处最该先改的

按影响排序，每条一句话，要具体到能动手。

## 记分：只记重复缺陷

不记总分。基准里只记一个数：

> **本轮与上一轮同题盲评，重复出现的缺陷有几条。**

- 重复 3 条 → 系统没动，改动无效，无论某一项看起来好了多少。
- 重复 1–2 条 → 动了一点，看是哪两条。
- 重复 0 条 → 真的变了，把导致变化的那条做法写进 [`从参考里取.md`](从参考里取.md)。

这个数不能靠加细节刷：新加的东西只会引入**新**缺陷，不会减少重复的那几条。

## 自评

**自评不能当盲评。** 这九轮里自评比盲评高 20–35 分，每次都是。
自评唯一的作用是让你看见"作者自己知不知道自己差"——写，但单独署名，不进重复缺陷的统计。
