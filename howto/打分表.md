# 打分表

门槛 **80**，最多两轮。

> **盲评委托里必须写清对照的是哪一张图。** 不写，评审会拿这个风格最有名的那批原作当尺子，
> 而你的目标可能只是其中一帧的改编——埃及那张卡四轮都栽在这里。**AI 只判事实项，品味项留给人。** 自评分只用来排序，不写成「已达标」。

| 项 | 分 | 怎么判 |
|---|---|---|
| 签名命中 | 35 | 对照第一步的「必须有」逐条打钩，**缺一条扣 7** |
| 媒介可信 | 20 | 见下面「媒介的四道硬指标」；缺两道以上，本项 ≤ 8 |
| 构图与叙事 | 15 | 是不是用了这个风格自己的组织方式；事件是否一眼看懂 |
| 人物与物体造型 | 15 | 有没有重量、有没有关系；一眼幼稚或像贴纸，本项低于 8 |
| 动态 | 10 | 活而不闪；动在事件上，不是全屏在抖 |
| 技术 | 5 | `check` 的确定性、性能、框景 |

## 媒介的四道硬指标

三次冷启动、三个不同媒介（木口木刻／麻胶版／铜版画）、三个独立审片人，给出的是同一句诊断：
**「矢量插画套了一层纹理」**。原因都一样——没有一条是媒介真正的特征。照着查这四条：

1. **标记是刻掉的，不是描上去的。** 版画的"线"是挖掉的地方，所以线宽随形体和明暗变，
   亮线暗线会互换；等宽的描边一出现，就不是版画。
2. **版与版之间错位。** 套色印刷必然对不准，交界处露一线纸白或叠出第三个颜色。
   零错位的套色是数码产物。
3. **亮部是纸，不是白色颜料。** 纸色（偏暖的米）当最高明度，且纸纹从最亮处透出来。
4. **同一块颜色内部墨量不均。** 墨有厚薄、有针孔、有边缘积墨；纯色填充是矢量。

缺两条以上 → 媒介可信 ≤ 8，且**签名命中必然也拿不到分**（因为刻线本身就是签名）。

同类硬指标对别的媒介也成立：油画看**笔触方向是否顺结构**、水墨看**飞白与渗化**、
壁画看**颜料吃进底子的洇边**、像素看**网格与调色板**。**没有硬指标的媒介，等于没有媒介。**

## 两项一票否决

- **签名命中 < 25**（5 条「必须有」缺了 2 条以上）。
- **主体一眼幼稚**（涂鸦感、贴纸感）。

任何一项触发，总分不用算，直接回第 2 步重做。

## 自评会虚高

**本仓库实测：埃及墓室壁画那一版，自评 82，盲评 47——差 35 分**，两项一票否决
（签名命中 21 < 25、造型 5 < 8）自评全没看见。

差这么多不是尺度问题，是自评在**给想要的结果找理由**。所以：

1. 分数表必须带**分项分**和**签名清单**，不许只写一个总分。
2. 独立复核分写在自评**旁边**，**以较低者为准**。
3. 卡的「短板」栏里只要出现一票否决项，状态不许写「实做」。
4. 两轮后仍低于 80：状态写「研究配方」，把卡住的点写进「短板」。
5. **更好的是先不写自评**：画完直接找盲评，省得给自己找理由。自评只在没有第二个人时用。

## 写法

```md
| 项 | 分 | 依据 |
|---|---|---|
| 签名命中 | 28/35 | 缺「栏带构图」「象形字密度」两条，各扣 7 |
| 媒介可信 | 17/20 | 灰泥斑驳可信；裂纹只有一条，右半张偏干净 |
| 构图与叙事 | 13/15 | 栏带成立；圣甲虫那一段的事件不够清楚 |
| 造型 | 12/15 | 少女的手偏薄；圣甲虫的腿读成了触须 |
| 动态 | 7/10 | 水纹 12fps 步进成立；阿顿光线幅度太小 |
| 技术 | 5/5 | 确定性通过，16.7ms/帧 |
| **合计** | **82** | 无否决项 |
```
