# 做一个新风格：六步

风格不是引擎里的一个选项。它是一份**量出来的规格**，加上一个**用代码画出来的实现**，加上一张**卡**。

这六步的顺序不能换。跳步的地方，就是画面变成「现代插画换了套色板」的地方。

---

## 1. 原作锚定：先看，再量

```sh
dsh-motion reference <参考视频> --fps 2      # 抽帧、切点、接触表
```

图片类参考直接摆在一起看。至少 **3 幅不同作品**，同一幅的局部、同一构图的换色不算。

然后**量色板**——这一步单独值 18 分（见 [涨分.md](涨分.md)）：

```sh
node scripts/palette-from.mjs <参考帧> --colors 8 --out out/ref-palette.png
```

输出的 hex 直接写进场景的色表。**手挑必偏亮偏灰**，实测差一档。

然后**第二件事是钉死对照物**：

> **我对照的是哪一张？** 一张，不是一批。写进卡的第一行，写进盲评的委托里。

埃及那张卡就是这么卡住的：四轮盲评都按内巴蒙墓的真壁画判，
而画面里的主角是原片那种平涂卡通——**只要主角是卡通，按壁画的尺子永远判"贴纸"**。
不是画得差，是**没写清拿哪把尺子**。

钉好对照物之后，**真的看**，写下四样东西：

- **5 条签名特征**，每条标一个等级：
  - `必须有` —— 缺一条，就不像这个风格
  - `加分` —— 有更好，没有也成立
  - `禁忌` —— 出现就毁
- **色板**：3–6 个色值，写明明处偏什么、暗处偏什么。不要声称这是艺术家的标准色。
- **这种画在物理上是怎么做出来的**：刷、刻、描、涂、贴、印。那个物理过程就是你的媒介通道的规格。

> 例（埃及）：必须有——无透视平涂、等宽深棕轮廓线、正面肩侧脸、栏带式构图、象形字密度。
> 禁忌——任何笔触噪点、渐变、透视缩短。

## 2. 按这个风格自己的构图逻辑重构图

不是搬原作的人物和坐标，是学它**组织画面的方式**：谁占一半画面、留白在哪、视线怎么把人咬合、切在哪。

写一句「这个风格的构图规则」，再按它给新题材定布局。

**同一个题材不许套第二个风格。**

## 3. 画形层，再过媒介层

两层，分开写：

- **形层**：把物、人、空间画干净。可以是 canvas 路径、离屏画布、像素栅格。
- **媒介层**：让形层过一遍真实画材。

`kit/` 里有两个通道（`broken` 重绘成笔、`fresco` 颜料吃进墙）和一套像素栅格（`pixel`，量化 + 1px 描边 + 抖动）。
**没有对应通道就写一个**，写在你自己的 `scenes/_<风格>.mjs` 里，不要往引擎里加。

**禁止在扁平矢量上叠一层噪点就算风格。** 法则是：媒介改变的是**形**，不是**表面**。

## 4. 一帧先行，并排对照

先出静帧，不先做动画。

```sh
dsh-motion render --stills 3 --out out/try
```

把这一帧和原作摆在一起看（`out/look/vs-ref.jpg`），只回答一个问题：**去掉签名，还认得出是谁的画吗？**

答不出来就回第 1 步，不要往下走。

## 5. 让它活：用这个风格自己的运动逻辑

一个主动作 + 2 个母题循环。

- 墨随风、笔触在呼吸、水面把倒影拉碎、壁画几乎不动但视线和交接在动。
- **不要所有风格都用同一套淡入淡出。**
- 运动量看**每帧改动**：连续（2–5%）是活的，跳变（>20%）是闪。

## 6. 打分，门槛 80，最多两轮

见 [`打分表.md`](打分表.md)。两项一票否决。

- 自己先打，分项分必须写出来。
- 再找**没参与制作**的人或 agent 复核，**以较低者为准**。
- 两轮后仍低于 80：登记为「研究配方」，把卡住的地方写进卡的「短板」，**不许登记为实做**。

---

## 登记：三档，凭证据

| 状态 | 意味着 | 不许做 |
|---|---|---|
| **研究配方** | 有来源和视觉假设，没实现或没画面验证 | 不许说「会做这个风格」 |
| **单场景实做** | 有实现、有输出、有并排图和打分记录，只覆盖那个场景 | 不许说「跨题材可用」 |
| **跨场景验证** | 不同新场景各自过审，写清覆盖范围 | 不许说「所有题材都行」 |

**先验证新场景，再把它说成能力。** 一个风格有一个题材成立，不代表整个风格成立。
